# 🌱 Pip & Nova — Intel Core Series 3 vs Core Ultra Series 3

A fun, interactive and beginner-friendly website that compares **Intel Core Series 3 (Pip)** and **Intel Core Ultra Series 3 (Nova)** processors.

The website uses playful mascots, colorful UI components, interactive comparisons, and a personalized quiz to help users understand which processor best suits their everyday computing needs.

## ✨ Features

- **Meet the Family:** Explore Pip and Nova through interactive processor cards.
- **Shared Architecture:** Learn about the technologies and features shared by both processor families.
- **Interactive Game:** Match different computing tasks with the processor that fits them best.
- **Side-by-Side Comparison:** Compare CPU cores, Xe3 graphics, NPU performance, platform AI performance, and memory speed.
- **Workload Recommendation:** Use an interactive slider to understand which processor is suitable for different workloads.
- **Personalized Quiz:** Answer five questions to discover whether Pip or Nova better matches your computing needs.
- **Responsive Design:** Optimized for desktop and mobile screens.
- **Light and Dark Mode:** Supports system theme preferences.
- **Animated UI:** Includes animated mascots, comparison bars, and interactive elements.

## 🛠️ Technologies Used

## 📊 Processor Comparison

| Feature | Pip | Nova |
|---|---|---|
| Processor Family | Intel Core Series 3 | Intel Core Ultra Series 3 |
| Codename | Wildcat Lake | Panther Lake |
| CPU Cores | Up to 6 | Up to 16 |
| Xe3 Graphics Cores | Up to 2 | Up to 12 |
| NPU Performance | Up to 17 TOPS | Up to 50 TOPS |
| Platform AI Performance | Up to ~40 TOPS | Up to ~180 TOPS |

*Specifications represent maximum configurations. Actual performance depends on the laptop configuration, cooling, memory, and workload.*

## 🚀 Getting Started

### Prerequisites

You only need:

- A web browser
- Visual Studio Code
- Live Server extension (recommended)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Brunda-tech/YOUR-REPOSITORY-NAME.git
   ```

2. Navigate to the project folder:

   ```bash
   cd YOUR-REPOSITORY-NAME
   ```

3. Open the folder in Visual Studio Code.

4. Open `index.html`.

5. Right-click and select **Open with Live Server**.

The website will open in your browser.

## 🎯 Project Objective

The main objective of this project is to make processor comparisons easier and more engaging for students and everyday users.

Instead of presenting specifications in a traditional technical table, the website transforms processor information into an interactive experience using visual comparisons, simple explanations, and personalized recommendations.
